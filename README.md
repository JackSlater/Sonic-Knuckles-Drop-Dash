# Sonic & Knuckles - Drop Dash Edition

Sonic & Knuckles ROM hack that adds the Drop Dash ability from Sonic Mania!

## Download

Grab the latest `skbuilt.bin` file from the releases.

## How to Play

Load the ROM in any Genesis/Mega Drive emulator:
- Gens
- Fusion
- BlastEm
- RetroArch

## Controls

**Drop Dash:**
1. Jump (press A, B, or C)
2. Hold the button while in the air
3. Land = instant speed boost!

That's it!

## Features

- Drop Dash just like Sonic Mania
- Spin animation speeds up while charging
- Spindash sound on release
- Doesn't work with shields (authentic behavior)

## Notes

- Currently only works with Sonic (not Tails/Knuckles)
- Based on Sonic & Knuckles (World) ROM
